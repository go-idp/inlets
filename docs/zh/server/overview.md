# 服务端概述

**Inlets 服务端**在公网终结 **HTTP**（含 WebSocket 升级）与 **TCP**，再通过隧道转发到已连接的客户端。

## 职责

- **控制面** — WebSocket（常见路径 `/_/monitor`）：鉴权、隧道生命周期、经典路径上的 HTTP 请求/响应封装。
- **HTTP 入口** — 按主机名路由到对应隧道；可在 YAML 配置 **边缘鉴权**（`tunnels[].auth`）。
- **TCP 枢纽** — 监听 `tcpPort`；接受用户连接并与客户端侧上游建连配对。
- **策略** — 按客户端/全局 **带宽**、无凭据监控 **会话时限**、**通知** 等。

## 协议

- **v2** — 现代客户端默认：能力协商，高吞吐时可走 **`/_/data`** 二进制通道。TCP 可协商 **`TCPEarlyStreamRegister`**，使客户端在首字节转发前就绪；未协商该能力的老 v2 客户端仍由服务端通过短延迟兼容。
- **Legacy v1** — 旧报文格式；客户端使用 `--legacy` 与 `--remote` / `--remote-tcp-port`。
