# 什么是 Inlets

**Inlets Go** 是在 **WebSocket** 长连接上传输 **HTTP** 与 **TCP** 的隧道实现。客户端与本地服务同机部署；服务端提供公网域名或 TCP 端口，把流量通过隧道转到客户端。

与通用反向代理相比，Inlets 围绕**控制面**（monitor）和为隧道优化的**数据路径**设计：鉴权、心跳、重连，以及 v2 下可选的独立 **data** 二进制通道。

## 适用场景

1. **暴露本地 Web** — 在 `127.0.0.1:8080` 开发，需要稳定的 `https://app.example.com`。
2. **SSH 或其它 TCP** — 将服务端公网端口映射到本机 `127.0.0.1:22` 等。
3. **Webhook / 回调** — 第三方访问公网 URL，流量到达你本机或内网。
4. **演示与联调** — 用 token 或 credentials 控制访问。

## 能力概览

- **HTTP 隧道** — 子域或主机路由到本地 HTTP；协商成功时可支持 WebSocket 升级与语义流式。
- **TCP 隧道** — 在服务端监听；每个入站连接中继到上游。
- **鉴权** — 共享 token、客户端凭据，或无凭据的临时 **public** 监控会话（可被服务端限时）。
- **协议** — 默认 **v2**（`--server` URL + 能力协商）；**legacy v1**（`--legacy`）兼容旧服务端。
- **服务端** — YAML 配置、**热更新**、全局/按客户端 **带宽限制**、**钉钉/飞书/企业微信/Slack** 通知。
